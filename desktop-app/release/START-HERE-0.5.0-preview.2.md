# Wayfinder 0.5.0-preview.2

This historical preview revises chat layout, drafts, scrolling and light/dark themes. The bundled backend and CPU memory model still require Docker Desktop with a local Linux engine and the existing managed Hermes/OpenShell setup.

Original checks: 70 frontend tests, 10 rendered scenarios, 18 packaged checks, 11 portable checks and 34 static package checks. These are the original build results, not new tests performed during publication. The full rebuild is incomplete; provider account writes, scheduling, Fitness and W37 native actions remain unavailable.

The executable is unsigned. Verify its adjacent SHA-256 checksum and read its verification JSON. Detailed historical evidence is in docs/platform/REBUILD-CHECKPOINT-02.md. For the connected pet and widget, use preview 4 instead.
