# Wayfinder 0.5.0-preview.4

This preview connects the GitHub pet/widget and animated chat overlay to the existing desktop runtime.

- Ctrl+Shift+Space opens companion chat in the space selected in the main window.
- The pet menu opens chat, the main app or widget settings; it can also hide the pet.
- Settings includes Show desktop pet and Open companion chat.
- Closing the main window hides it; use Wayfinder > Quit to stop the app.

Python, the backend and CPU memory model are bundled. Docker Desktop with a local Linux engine and the existing managed Hermes/OpenShell installation are still required. This executable is unsigned. See the adjacent verification JSON and checksum for exact test evidence. The full product rebuild and the previously reported graph-lease qualification issue remain open.
