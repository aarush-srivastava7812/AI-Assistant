The binaries are release assets rather than Git source files. All uploaded assets were verified against their local SHA-256 hashes; [publication evidence](../../docs/platform/DESKTOP-RELEASES.json) records each URL, size and digest. Original verification reports describe their respective builds; publication does not add test coverage.

These unsigned executables bundle the application Python backend and CPU memory model. Preview 5 Setup additionally installs a private official Hermes SDK/Python runtime and offers Docker Desktop installation; Windows virtualization, permissions and possible restarts still apply. Bring your own provider API key; preview 6 supports multiple providers. Google sign-in currently requires your own Desktop client JSON. Older versions retain their documented prerequisites. The full product rebuild remains unfinished; attached verification reports state the coverage and limits for each build.
