# OpenCode provider onboarding research

Research date: 2026-10-30. OpenCode CLI 1.19.5 source commit: `810c0eba1a7348036f8bdf61e6632d0c36c6876c`.

REA completed a selected static analysis in 10.45 seconds. Evidence: `ev_f12b9c5717a494f37730e520e99402fffc5eaeed08f765e06894585df27c3e90`. Selected source digests, scope, statistics, and limits are in [the evidence record](OPENCODE-PROVIDERS-REA-EVIDENCE.json). Raw local evidence is retained in `.local/opencode-research/providers-analysis.json`. This is source analysis of the official CLI boundaries, not decompilation of its native Windows executable or observation of live vendor accounts.

The [provider dialog](https://github.com/anomalyco/opencode/blob/810c0eba1a7348036f8bdf61e6632d0c36c6876c/packages/tui/src/component/dialog-provider.tsx) orders popular providers, separates API-key and OAuth methods, tracks connected providers, and offers a custom provider. API-key submission writes a provider-specific credential, refreshes provider state, and leads to model selection. The [model dialog](https://github.com/anomalyco/opencode/blob/810c0eba1a7348036f8bdf61e6632d0c36c6876c/packages/tui/src/component/dialog-model.tsx) searches model choices and tracks favorites and recent choices. The [provider router](https://github.com/anomalyco/opencode/blob/810c0eba1a7348036f8bdf61e6632d0c36c6876c/packages/opencode/src/provider/provider.ts) selects a bundled SDK from the configured npm identity; native Anthropic and Google transports differ from OpenAI-compatible Chat Completions and OpenAI Responses.

Wayfinder applies those findings with a searchable provider picker, provider-specific key help, masked/revealable key entry, saved-key reuse, model suggestions and a custom model ID field. A single Connect and verify button saves the encrypted credential and sends the disclosed short test prompt. Editing the provider, model, key or endpoint invalidates the displayed verification and subsequent consent. Settings can reopen model setup while preserving spaces and conversations.

The shared catalog supports OpenAI, Anthropic, Google Gemini, OpenRouter, NVIDIA, DeepSeek, Groq, xAI, Mistral, Together AI, Fireworks AI, Cerebras, Perplexity, Moonshot/Kimi, Z.AI, DeepInfra, Alibaba/Qwen, MiniMax and custom HTTPS OpenAI-compatible Chat Completions APIs. Model suggestions are examples from the pinned executable's bundled catalog, not a guarantee of live account availability; an account-specific model ID can be entered. [Catalog evidence](OPENCODE-PROVIDER-CATALOG.json) records model status and SDK metadata. The public Models.dev endpoint returned HTTP 403; the official executable's `models --verbose` command was inspected with model fetching disabled and synthetic credentials in an empty isolated profile. No model calls or live credential validation occurred in that catalog probe. Perplexity Sonar examples come from its provider documentation because the pinned executable did not expose that provider in this probe.

OpenCode uses native SDKs for OpenAI Responses, Anthropic Messages and Gemini; the other catalog entries use its bundled compatible SDK. Optional Hermes source workers use matching Responses/Messages or compatible Chat Completions, including Google's documented compatibility endpoint. Only the selected key enters the isolated child environment. Keys stay out of renderer status, arguments, chat, logs and OpenCode auth files. Windows account encryption replaces OpenCode's plain auth.json persistence for Wayfinder. Existing encrypted NVIDIA profiles retain their original provider consent pin until edited.

This implements API-key connections. ChatGPT/Copilot subscription OAuth, AWS IAM/Bedrock credentials, Google Vertex service accounts and Azure resource/deployment authentication are separate methods and are not represented as working API-key connections. Custom endpoints must speak HTTPS OpenAI-compatible Chat Completions. No subscription tokens are treated as API keys.

The extra desktop menu strip is removed. A light draggable caption surface retains native minimize, maximize and close controls. Settings includes a named Quit Wayfinder action so companions can remain enabled without losing an explicit application exit.

References: [OpenCode providers](https://opencode.ai/docs/providers/), [OpenCode config](https://opencode.ai/docs/config/), [Google OpenAI compatibility](https://ai.google.dev/gemini-api/docs/openai), [AI SDK providers](https://ai-sdk.dev/docs/foundations/providers-and-models). Verification results are in [the release validation](PROVIDERS-VALIDATION.md).

The EXE validation also exposed a native Windows worker protocol defect: unescaped Unicode output could use a legacy stdout code page while the parent parsed UTF-8. The runner now emits ASCII JSON escapes, preserving the original Unicode after parsing. Regression tests execute its actual output block with cp1252 and ASCII stdout using accented text, Chinese and emoji.
